# EventHub Project Bible

## Identity

-   **Name:** EventHub
-   **Formal title:** EventHub --- A MERN-Based Event Management and
    Registration Platform
-   **Type:** General-purpose event management and registration web
    application
-   **Academic context:** B.Tech CSE project
-   **Level:** Beginner to intermediate
-   **Current planned stage:** Step 1 --- start the tutorial and set up
    the project

## Product vision

Provide a central place where attendees discover and register for
events, organizers manage events and participants, and administrators
oversee platform activity.

## Roles

-   **User/attendee:** discover events, register, view registrations,
    manage profile.
-   **Organizer:** create and manage events, review participants, view
    event statistics.
-   **Admin:** manage users and organizers, moderate events, review
    registrations and platform statistics.

## Stack

React, React Router, Axios, Node.js, Express.js, MongoDB, Mongoose, JWT,
bcrypt, Git, and GitHub. Potential hosting: Vercel, Render, and MongoDB
Atlas.

## Core data concepts

-   User
-   Event
-   Registration

See `DATABASE_SCHEMA.md` for the initial logical design and
`API_CONTRACT.md` for proposed API areas.

## Priorities

1.  Make the basic tutorial application run.
2.  Understand and implement the backend and database.
3.  Add authentication and authorization.
4.  Implement event CRUD and registration.
5.  Customize into EventHub.
6.  Test and deploy.
7.  Add advanced features only after the core is stable.

## Product guardrails

-   Keep the main platform general-purpose; College Events is a future
    module.
-   Treat tutorial code as a learning foundation, not an unchanged final
    submission.
-   Do not claim a feature is complete until it is implemented and
    tested.
-   Enforce authorization, duplicate-registration checks, and capacity
    rules on the backend.
